# ClearVote Team Roles

## Project Management — Orator

* Manage project timeline, tasks, and documentation
* Coordinate work across teams
* Track sprint progress and blockers
* Make sure all components integrate correctly

## UI/UX & Frontend — Tadiwa

* Design the browser extension interface
* Build the ClearVote website frontend
* Display warnings, results, and supporting information
* Connect the frontend to the backend API

## Backend / API — Vensen & Henry

* Build and maintain the backend API
* Receive content from the browser extension/frontend
* Integrate the tested AI/ML model provided by Tatenda
* Send analysis results back to the frontend
* Integrate external APIs and reliable-source data
* Make sure the backend, AI model, and frontend communicate correctly

## AI / ML — Tatenda

* Research and select the AI model, transformer, or other approach used for content analysis
* Set up and test the selected model
* Evaluate model performance and limitations
* Define the model's expected inputs and outputs
* Deliver a tested, working model that can be integrated into the backend

## Research Responsibilities

* **Existing tools / fact-checking research:** Henry
* **APIs, models, and datasets:** Vensen & Orator
* **AI model selection and testing:** Tatenda
* **Privacy, ethics, and social-media considerations:** Tatenda
* **Digital well-being research:** To be assigned

## Shared Responsibility

All team members are responsible for:

* Documenting their work
* Communicating blockers
* Testing their component
* Following agreed integration requirements
