# ClearVote Roadmap

## Fall 2026

### Phase 1 — Planning & Research

**August–September**

* Finalize MVP and system architecture
* Confirm team roles
* Research models, APIs, datasets, and existing tools
* Set up GitHub workflow and documentation

### Phase 2 — Prototype Development

**Late September–October**

* Build browser extension prototype
* Build backend/API
* Select and test AI/ML model
* Build initial ClearVote website
* Begin component integration

### Phase 3 — MVP Integration & Testing

**October–Early November**

* Connect frontend, backend, and AI/ML components
* Test end-to-end product flow
* Fix major bugs
* Prepare MVP demo

### Phase 4 — Fall Review

**Before November 16**

* Review MVP progress
* Document issues and lessons learned
* Plan improvements for Spring 2027

## Spring 2027

### Phase 5 — Improvements & Pilot

**January–February**

* Improve model and user experience
* Add reliable-source integration
* Conduct small user testing
* Prepare campus pilot

### Phase 6 — Campus Launch & Evaluation

**March–April**

* Run ClearVote campus activities
* Collect feedback and engagement data
* Improve the product based on results

### Phase 7 — Final Evaluation

**April–May**

* Analyze project impact
* Finalize documentation
* Prepare fellowship presentation and final report
