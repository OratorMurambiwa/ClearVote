## User Flow

1. User browses political content.
2. ClearVote displays a small warning when relevant evidence is found.
3. User opens the extension for a short summary.
4. User selects **Learn More**.
5. ClearVote opens the detailed results page with evidence and sources.

## Design Notes

- Light and dark modes follow the user's system/browser theme.
- Warnings are designed to be small and non-intrusive.
- Results focus on evidence and uncertainty rather than simply labeling content true or false.
